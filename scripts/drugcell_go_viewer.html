Graph scope. The left panel is DrugCell's released, already-pruned GO. The middle panel adds the latest adaptive knowledge product; the right panel applies the size, separation and depth pruning rules to that graph. Each dot is a term or functional module. All 3,008 input genes remain covered.

Layout and edges. Vertical coordinates use longest root-to-node depth in the augmented input, with a compact grid inside each depth band. Surviving nodes keep their coordinates after pruning. Hierarchy edges run from parent to child. A gene view adds direct membership edges. Released hierarchy rows encode a common edge type; the input file does not distinguish is_a and part_of. Node area increases with the square root of propagated gene count.

Evidence. Source labels and evidence classes come from the frozen knowledge product. Node color identifies the concept origin; an existing GO term may also receive literature support. The upstream evidence records retain biological conditions and relationship details.
