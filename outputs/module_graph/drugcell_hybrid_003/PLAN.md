# Group-recipe timing experiment

Process the same 24 scientific source modules as the preceding placement pilot, on the same original graph and fixed 3,008-gene universe. One 24-module batch lets the editor select coherent groups, equivalent-concept reuse, shared anchors and individual exceptions. Code expands only the approved group scopes and source-native hierarchy, preserving each declared membership. An independent reviewer sees every module and expanded connection, and returns group verdicts with module exceptions.

Measure total placement wall time, editor/reviewer time, request count, shell calls, token usage, context bytes, added/reused/deferred decisions, expanded relations and survival under the same DrugCell pruning rules. Compare against the frozen historical pilot outside the task-only agent workspace. The comparison measures the combined recipe, batching, compact context and corrected runtime configuration. Source acquisition belongs to the shared input workflow.

Scientific inputs and model/reasoning settings match the earlier pilot. The knowledge product is frozen before any downstream evaluation.
