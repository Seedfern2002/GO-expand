# 生物学评测设计

研究主张：agent 根据不同任务的知识需求组织 GO 增广，能够在多种生物学任务上改善功能表示和下游效果。评价重点是规模、多任务普适性及生物学有效性。

组学／生物数据库的规则化增广与文献内容增广均在评价范围内。不同任务可以使用不同知识类别与增广路径，共用 agent 框架。GEARS 是重点应用之一。

## 增广与评测流程

agent 的输入为任务类型、研究对象、生物学背景及需要补充的知识类别。以扰动预测为例，知识重点可以是通路、调控联系和功能模块。候选知识来自外部文献和生物数据库，是否纳入依据证据支持、语义一致性及与任务知识需求的相关性。

任务说明和知识类别在增广前确定，增广产物在下游训练与评测前冻结。预测误差、验证分数和测试结果仅作为评价输出，不参与 agent 的候选选择、编辑或产物筛选。

## 两条实验轨道

1. **任务适配：** 相同 agent 方法依据各类任务预先定义的知识需求，生成并冻结各自的 GO overlay，再进行下游训练和评测。
2. **知识迁移：** 将为某类任务构建的冻结 overlay，直接用于其他模型、数据集或生物学读出。

每次编辑记录属于 ontology、annotation、情境活动层还是派生图投影。多个模型消费同一知识属于跨模型评价；独立的成像或遗传互作读出提供另一种生物学证据。

## 任务矩阵

| 任务 | 资源／消费者 | 目标观测量 |
|---|---|---|
| 未见转录扰动（重点应用） | GEARS；Norman／Replogle | 表达变化、方向、扰动检索；按基因覆盖分层 |
| 功能相似度 | 固定 GO 集合／投影与独立实验 profile | 邻居检索、排序一致性、模块恢复 |
| 形态表型 | JUMP CRISPR／ORF | 冻结源增广后的形态邻居检索或预测 |
| 遗传互作 | 独立组合筛选 | 协同、缓冲等互作的恢复与排序 |
| 药物响应 | SparseGO／DrugCell | 未见细胞系或药物的响应与机制 |
| 功能解释 | 固定 ORA／GSEA | 已知实验过程的恢复与跨重复一致性 |
| 历史知识恢复 | 固定 GO 历史快照与时间限定资料 | 后续新增关联／概念的恢复及证据质量 |

对应资源和论文见 [文献地图](literature.md)。具体划分、指标及验收阈值在接入各数据集后确定。

不同数据集、模型和细胞环境描述同一任务类型内的适用范围；多任务普适性覆盖上述不同任务类型。

## GEARS 场景中的比较

固定 GEARS 模型实现、共表达图、预处理与划分，替换 GO 来源：

- 原始 GO。
- 相同证据资源及增广预算下、未指定任务知识重点的通用补全。
- 任务指导剪枝。
- 根据任务知识需求构建的增广，例如侧重通路和调控知识的扰动预测增广。
- 增广后剪枝。
- 匹配编辑量的随机对照、度数匹配图对照。

对原始／增广 GO 同时使用一个简单 GO 特征预测器，测量知识贡献。分别报告原始设置和重建设置，明确是否变化了注释传播、根 term、aspect、top-k 或边权。

增加知识类别消融，例如通路知识、调控知识及二者组合，分别冻结后运行统一评价。各类别、组合及投影规则在评测前确定，比较其各自贡献。

## 从表示走到机制

1. 记录每条编辑改变了哪些注释闭包和邻居。
2. 用独立 profile 判断新增邻居是否具有实验功能联系。
3. 对预先确定的知识类别或编辑组做移除消融和独立重训，定位预测收益；消融结果作为机制分析记录。
4. 汇总低覆盖基因、功能模块与细胞情境中的收益分布。
5. 从可重复的信号里选择新的基因–过程／遗传互作候选，开展独立数据验证或实验。

同一过程中的激活和抑制因子可能产生相反方向的响应。功能相似度与有符号的干预相似度分别定义、分别评价。

## 数据与统计记录

- train/validation/test 在实验前固定；agent 根据任务说明及外部知识构建增广，候选选择不读取各划分中的目标响应或预测结果。
- 用于评价的实验读出及其直接衍生标签与增广证据分离，并按来源记录重叠情况。
- 以独立扰动／实验／细胞系为统计单位；报告重复训练及合适的置信区间。
- 保存所有候选编辑、知识类别及证据／语义审查的纳入或排除理由，同时记录 token、检索与训练成本。
- 历史恢复实验记录模型知识时间范围和证据日期；日期限定的检索资料与模型内部知识分开描述。
- 增广阶段记录来源支持、语义一致性和任务知识相关性；评测阶段另行记录下游效用。
